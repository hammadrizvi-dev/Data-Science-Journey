## 📌 Project 01: Student Performance Analysis

### 🎯 Overview
An exploratory data analysis project focused on understanding the socio-economic and demographic factors affecting student test scores across math, reading, and writing.

### 🛠️ Tech Stack & Methods
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Techniques Used:**
  - Handling missing data and type casting.
  - Granular slicing using `.loc`, `.iloc`, and boolean filters.
  - Multi-variate aggregation using `.groupby()` and `.pivot_table()`.
  - Score distribution and outlier detection.

### 📊 Key Insights Found
1. **Parental Education:** Higher levels of parental education showed a direct positive correlation with composite test scores.
2. **Test Preparation Course:** Students who completed the preparation course scored 10-15% higher in critical reasoning and writing sections.
3. **Gender Distributions:** Balanced overall distributions with distinct variances across quantitative vs. analytical sections.
